# BBDD Sakila

Contiene un conjunto de consultas SQL realizadas sobre la base de datos **Sakila** usando **DBeaver**.  
Incluye consultas sobre películas, actores, clientes, alquileres, categorías e inventario.

## Contenido

- Queries de ejemplo:
  - Películas por categoría, duración y clasificación
  - Actores y su participación en películas
  - Clientes y sus alquileres
  - Inventario y disponibilidad de películas
  - Estadísticas como conteo de alquileres, películas por categoría, etc.
